# 周报结构

适用：周报、项目进展、工作总结。先出大纲 JSON，再渲染可编辑 `.docx`。

## 默认结构

1. 标题与汇报区间
2. 本周进展（可量化）
3. 问题与风险
4. 下周计划
5. 需协调 / 决策事项

## 文案约束

- 一条一事；进展尽量带结果而非过程
- 数字带来源（若材料中有）
- 不使用绝对化宣传（第一、绝对、100% 除非材料写明）
- 风险写清影响与拟议对策
- 不要把 PPT 口吻写成整段空话

## 流水线

1. 收集用户指令与附件摘录
2. `outline_report` 得到 JSON
3. `draft_docx` 渲染 Word
4. 下载后在 Word / WPS 中再改
